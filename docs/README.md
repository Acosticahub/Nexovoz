# Proyecto Nexovoz

Plataforma web para ejercicios de lenguaje y fonoaudiología.

---

## Archivos del proyecto

```
Nexovoz/
│
├── 1Inisiodesesion.html      → Pantalla de Login
├── 1 2registro.html          → Pantalla de Registro
├── nexovozinicio.html        → Pantalla principal (después de login)
├── 3pruebadevoz.html         → Prueba de voz
├── 5foro_con_boton_inicio.html → Foro
├── biblioteca_lenguaje.html  → Biblioteca
├── ejercicios_lenguaje.html  → Ejercicios
├── agendar_cita_fonoaudiologia.html → Agendar citas
│
├── login.php                 → Verifica usuario y contraseña en la BD
├── registro.php              → Guarda un nuevo usuario en la BD
├── conexion.php              → Conecta PHP con la base de datos
├── cerrar_sesion.php         → Cierra sesión y vuelve al login
├── pruebadevoz.php           → Guarda resultados de la prueba de voz
│
├── 1inicioestilos.css        → Estilos del login y registro
├── styles.css                → Estilos de la prueba de voz
├── script.js                 → Lógica de la prueba de voz
│
├── nexovoz.sql               → Base de datos (se importa en phpMyAdmin)
│
└── docs/
    ├── README.md             → Este archivo
    ├── guia-xampp.md         → Cómo ejecutar con XAMPP
    └── guia-wampp.md         → Cómo ejecutar con WAMPP
```

---

## ¿Cómo abrir el proyecto?

Lee la guía según el programa que uses:
- **XAMPP** → [guia-xampp.md](./guia-xampp.md)
- **WAMPP** → [guia-wampp.md](./guia-wampp.md)

---

## ¿Por dónde empieza el proyecto?

Abre en el navegador:
```
http://localhost/Nexovoz/1Inisiodesesion.html
```
